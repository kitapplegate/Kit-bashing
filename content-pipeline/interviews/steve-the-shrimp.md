## Reference: technical summary of shrimp-desk (Steve), compiled by the drafter from the actual repo

Source: `C:\AI\shrimp-desk`, inspected 2026-08-12 (code, `requirements.txt`,
`start-shrimp.cmd`, and `git log` — commit messages, timestamps, diffs).
Facts only — not a voice source, none of this is Kit's own phrasing.

Steve (repo name `shrimp-desk`) is a Python app. The window itself runs on
tkinter, which ships with Python on Windows, so the GUI needs no extra
install; `pystray` draws the system-tray icon and `Pillow` handles images.
The tank canvas is drawn at a native 160×120 pixels and scaled 2x on
screen. It's a borderless, always-on-top, draggable window — closing it
(the X, or Escape) doesn't quit the app, it hides it back to the tray;
the app keeps running and the shrimp keeps living, which is the explicit
point per the code's own comment ("the shrimp is supposed to still be
there when you come back"). It launches through `pythonw.exe` (a
console-less build of the Python interpreter) via `start-shrimp.cmd`,
specifically because an earlier version tied the pet's life to the
terminal window it was started from — closing that terminal killed it.
A lock file stops two copies from fighting over one save file.

The entire commit history — 11 commits — is dated to a single day,
2026-08-02, running from 11:12 AM to 7:34 PM. Claude Opus 5 is credited
as co-author on every commit. One real bug from that day: shrimp hidden
to the tray had their movement tied to whether anything was actively
rendering them, so an unwatched shrimp didn't just stop being drawn — it
stopped actually simulating, freezing until someone looked again. Fixed
once measurement showed composing a frame cost roughly 7,000x more than
actually moving the animal, so there was never a real reason to gate the
two together.

The friends/community vision Kit describes above isn't just an idea —
stage 1 of it already exists and is working, built the same day. A
"neighbourhood" hub: each friend's running shrimp reports a small status
snapshot (a few hundred bytes) to the hub roughly once a second; the hub
redraws everyone's tank into one shared wall image using the same
renderer, with each tank's lighting following its own keeper's real
time of day, so a friend two time zones away is shown asleep in their
own night. No shrimp ever leaves its owner's machine — only the status
snapshot does. Stage 2 (looking after a friend's shrimp while they're
away) is intentionally not built yet, because Kit's design notes say it
needs the friend's permission first.
