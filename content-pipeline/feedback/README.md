# Editorial feedback records

One file per post. These records preserve Kit's exact reactions and the text
that caused them. `EDITORIAL-MEMORY.md` contains only the short lessons that
future sessions need every time.

Use the post slug as the filename. Record feedback without cleaning Kit's
quoted wording.

## Template

```md
# <Post title>

## <Stage or decision>

**Original:**

> Exact wording

**Kit:**

> Exact response

**Approved result:**

> Final wording or decision

**Lesson:** A narrow description of what this example teaches.

**Status:** Provisional | Standing
```
